Nexo AI Studio ("the Application", "the Extension") strictly respects your privacy and is 100% committed to protecting your personal data, tokens, and code privacy.

---

### 1. Zero Telemetry & 100% Local-First Storage
- Nexo AI does **NOT** collect, transmit, distribute, track, or sell any of your personal data, chat logs, code, or browsing history to any external servers or third parties.
- All data generated by the studio—including custom subagents, memory graphs, project files, local workspace code, and custom personas—is stored strictly locally on your own device using encrypted local browser storage APIs (`chrome.storage.local`) or Android app private storage (`SharedPreferences`).

---

### 2. Encrypted Token Vault & Security
- If you save a GitHub Personal Access Token or API keys in the **Token Vault**, the credentials are encrypted and stored solely in your local secure vault.
- Tokens are intercepted from chat to protect them from exposure, are never logged, and are only transmitted via HTTPS directly to official API endpoints (such as `api.github.com`) when you explicitly command the autonomous agent to commit or push code.

---

### 3. Third-Party Integrations & Sandboxes
- **Model Processing**: The app interfaces with AI models on client-side WebViews. Refer to the model provider's privacy policy for their inference terms.
- **Sandboxed Execution**: Code execution (Python via Pyodide, JS via safe sandbox) runs 100% in isolated, client-side web workers and iframe sandboxes on your own machine.
- **Web & GitHub Readers**: If you explicitly invoke web fetch, search, or GitHub repository imports, the app connects directly to the specified public HTTPS endpoints to download the requested content onto your local device.

---

### 4. Android App Security & Permissions
Nexo AI for Android wraps the AI studio locally inside a full-featured native WebView container.

**Android Permissions:**
- `INTERNET`: Required solely to communicate directly with chat servers and perform user-requested Git/Web sync.
- `RECORD_AUDIO`: Optional. Used strictly on-device for voice input & audio recording features when enabled by you.
- `STORAGE / MEDIA`: Used only to save your generated files, Word documents, Excel spreadsheets, PowerPoint slides, and zip project archives to your device's Downloads folder.
